# Technical Overview
## OOP
Entire project is build using the OOP Paradigm 
## Networking Protocols 
Designed and implemented [`custom networking protocols`](src/neat_networking_protocols.py) to allow for encrypted communication using RSA to create a secure tunnel to send the symmetric key and AES to encrypt the data
## Symmetric Encryption
Built [`a python implementation of AES`](src/class_based_aes.py) from scrach after researching and understanding each stage in the encryption process.
## Client Server Architecture
Designed and built a client server connection building upon the networking protocols to ensure a consistent and stable connection across a network.
## Database
Designed and implemented an [`SQL Database`](src/serverDatabase.py) normalized to 3NF
